# SincronizaHANA-SQL
Sincronizacion entre SQL Server y SAP HANA

Para utilizar esta aplicación, utilizamos el controlador odbc driver 18 para SQL Server 
También se usa streamlit en Python para poder generar la interfaz en un navegador web: pip install streamlit, asegurate de instalarlo en un entorno virtual
Ejecutas la aplicación con este comando: streamlit run aplicacion.py
